# 🐺 Wolf of Almaty Street

> *От уличного продавца до хищника рынка. Торгуйся, блефуй, доминируй.*

**Wolf of Almaty Street** — сатирическая 2D web-игра про торговлю, переговоры и продажи на улицах Алматы.  
Игра вдохновлена энергией агрессивного капитализма из *The Wolf of Wall Street*, но адаптирована под локальный алматинский вайб.

🌐 **Играть онлайн:**  
https://wolf-of-almaty-street-game.vercel.app/

---

## 🎮 Об игре

Ты начинаешь как бедный уличный продавец, который торгует максимально странными товарами:  
*Воздух из Нуроты*, *сломанный iPhone 6 как винтаж*, *ржавые чипсы с Медеу* и другие сомнительные “активы”.

Твоя задача — торговаться, блефовать, закрывать сделки и постепенно стать настоящим **Wolf of Al-Farabi**.

Каждый клиент пытается сбить цену. Некоторые клиенты — мошенники под прикрытием. На кону крупные контракты, ежедневные цели и ограниченное время.

**Сможешь ли ты выполнить дневной план и выжить на рынке?**

---

## 💡 Идея продукта

На первый взгляд это сатирическая 2D игра.  
Но под капотом — это MVP **gamified sales training platform**.

Игра помогает тренировать реальные навыки:

- переговоры;
- работу с возражениями;
- ценообразование;
- умение держать цену;
- распознавание мошенников;
- закрытие сделок;
- принятие решений под давлением времени.

Сегодня это игра про Алматы.  
Завтра эту механику можно масштабировать для:

- sales teams;
- университетов;
- HR onboarding;
- retail training;
- real estate sales;
- B2B sales training;
- startup pitching simulations.

## ✨ Возможности

- 🤝 **Система переговоров** — у каждого клиента свой характер: Aggressive, Friendly, Stubborn, Impulsive. Игрок может держать цену, давать скидку, усиливать ценность товара или уходить из сделки.
- 🕵️ **Распознавание мошенников** — некоторые клиенты маскируются под обычных покупателей. Нужно замечать red flags и использовать Counter-Pitch.
- 📋 **Крупные контракты** — сделки до $8,000, требующие харизмы и правильной стратегии закрытия.
- ⏱️ **Таймер дня** — 3 режима сложности: Hardcore, Normal и Rookie.
- 📊 **Отчёт в конце дня** — дневная выручка, ранг, лучшая сделка и серия успехов.
- 🏆 **Live Multiplayer Leaderboard** — рейтинги игроков в реальном времени через Supabase.
- ⚔️ **Raid System** — можно отправить мошенника другому игроку в следующую сделку.
- 💾 **Auto-save** — прогресс автоматически сохраняется в localStorage.
- 🎭 **45+ уникальных клиентов** — персонажи в алматинском стиле со своими историями и поведением.
- 🏅 **6 уровней ранга** — от Rookie Hustler до Wolf of Al-Farabi.
- 🎬 **Cinematic cutscenes** — анимации после старта игры и первой успешной продажи.

## ⚙️ Локальный запуск

### Требования

- Node.js 18+
- Аккаунт Supabase, если нужен leaderboard и realtime-функции

### 1. Клонировать репозиторий

```bash
git clone https://github.com/aybaris901-integ/Wolf-of-Almaty-Street-Game.git
cd Wolf-of-Almaty-Street-Game
2. Установить зависимости
npm install
3. Настроить Supabase
Создать проект на supabase.com
Открыть SQL Editor
Запустить содержимое файла:
supabase/schema.sql
Перейти в Project Settings → API
Скопировать URL и anon public key
4. Настроить переменные окружения

Создать файл .env.local:

cp .env.local.example .env.local

Заполнить значения:

NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key-here
5. Запустить проект
npm run dev

Открыть в браузере:

http://localhost:3000
🎯 Как играть
Выбери товар из инвентаря. У каждого товара есть скрытая себестоимость.
Клиент делает первое предложение — почти всегда слишком низкое.
Веди переговоры с помощью доступных действий:
Hold Firm — держать цену, но терпение клиента падает;
−10% Discount — небольшая скидка, чтобы сохранить интерес;
−25% Discount — большая скидка, которая спасает сделку, но режет маржу;
Pitch Value ⚡ — усилить ценность товара с помощью Focus Energy;
Walk Away — уйти из сделки, но есть шанс, что клиент вернётся с лучшим предложением.
Следи за мошенниками — они выглядят как обычные клиенты, но могут украсть деньги.
Используй Counter-Pitch, чтобы развернуть ситуацию против мошенника.
Выполняй дневной план — три провальных дня подряд приводят к Game Over.
